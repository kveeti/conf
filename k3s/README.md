# Retired Kubernetes cluster

This cluster is no longer in use. Its apps now run as NixOS services or Podman containers.

The manifests remain here for reference. Do not reconcile or redeploy them against the retired cluster.

VLAN 50, the retired node inventory, and the k3s/control3/storage Nix modules have been removed. The old VM disk images remain on ATX for recovery; their former configuration is in Git history.
